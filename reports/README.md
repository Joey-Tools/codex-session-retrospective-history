# Reports

This directory contains redacted human-readable retrospective reports.

- `daily/YYYY/MM/DD.md`
- `weekly/YYYY/MM/DD.md`
- `baseline/90-day-windows/YYYY-MM-DD_to_YYYY-MM-DD.md`

Reports should summarize host coverage, episode/topic trends, prompt improvement
candidates, verification gaps, and safety/privacy flags without quoting raw
transcripts.
Report filenames must not contain customer, repository, host, session, or raw
topic identifiers.
